# Sicherheit

p5converter ist für den Betrieb im Heimnetz gedacht. Wenn du die Oberfläche von außen erreichbar machst, schalte unter Einstellungen → Anmeldung ein Passwort ein und stell den Dienst am besten hinter einen Reverse-Proxy mit HTTPS.

## Eine Sicherheitslücke melden

Bitte melde Sicherheitslücken nicht als öffentliches Issue. Nutze stattdessen auf GitHub unter **Security → Report a vulnerability** die private Meldung (Security Advisories). Beschreib kurz, was du gefunden hast und wie es sich nachstellen lässt. Ich melde mich so bald wie möglich zurück.

Unterstützt wird immer die neueste Version.
