Windows-App (Test-Version vom Branch dev).

**EINE Datei:** `p5converter-setup.exe` laden und starten. Windows meldet beim ersten Start einmal „Unbekannter Herausgeber“ (die Datei ist nicht mit einem Zertifikat signiert): **Weitere Informationen → Trotzdem ausführen**. Danach durchklicken – fertig.

Enthält Programm, ffmpeg und alles Nötige. Die Oberfläche öffnet in einem eigenen Fenster; Hardware (Intel Quick Sync, NVIDIA, AMD) wird automatisch erkannt. Installation nur für dein Konto, keine Administrator-Abfrage.

Diese Vorabversion wird bei jedem Update von `dev` ersetzt.
